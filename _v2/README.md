# Lightman V2

Sitio estático creado desde cero, preservando negro, blanco y rojo de Lightman. Estructura de catálogo: categorías, fichas, galería y solicitud por WhatsApp.

## Generar

`node _v2/build.mjs`

Datos editables en `_v2/catalog.mjs`. Estilos y comportamiento en `assets/v2/`. El generador escribe las páginas HTML en la raíz; Jekyll las copia sin transformar. Las propuestas existentes conservan su plantilla e integraciones.

## Dominio y publicación

El dominio lightmanperu.com se administra en Hostinger y apunta a GitHub Pages. No se encontró un plan PHP/HTML contratado en Hostinger. La V2 reemplaza el contenido del mismo destino sin modificar DNS ni correo.
