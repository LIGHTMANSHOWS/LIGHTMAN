CÓMO ESTÁ ARMADO

Una base modular, un cálculo claro.

Cada segmento corresponde a un tubo de 1,20 m. No se fraccionan tubos para ajustar las medidas. Los modelos quedan abiertos en la base, sin LED cruzando el paso. La geometría muestra dimensiones entre ejes de tubos; uniones, bases y tolerancias se validan para fabricación.

La vista de luz es una simulación. El precio sigue los tubos del modelo; el diseño de estructura, la altura libre útil y el sistema de control se revisan para cada montaje.
