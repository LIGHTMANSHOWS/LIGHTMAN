Un timeline para el show

Selecciona un bloque para cambiar su figura, color, duración o zona LED. Arrastra los bloques para moverlos. Su borde derecho cambia la duración. Abre la flecha del traje para editar cada mano. Doble clic en una pista vacía crea un bloque.

Marcadores: M marca el tiempo exacto. R o Mayús + arrastrar crea un rango. Arrastra una figura o un efecto a ese rango para rellenarlo. F rellena con el efecto seleccionado. Alt permite mover sin ajuste. Escape cancela el arrastre y detiene la salida. Ctrl+Shift+Z rehace. Arrastra la división sobre los controles para ampliar el timeline.

Los proyectores tienen figuras animadas y transición geométrica. Las manos tienen encendido y apagado, sin fades. Los trajes usan el motor CPU de efectos de LDP y el patch de ejemplo Portion X Jacket.

Exportar show incluye el proyecto, las tres secuencias ILDA, efectos y patch LED, el estado de las manos y el audio. La música de la demo es una composición generada para esta entrega.

El recorrido 3D ilustra la composición escénica. La calibración física de velocidad, amplitud y blanking depende de cada proyector.
