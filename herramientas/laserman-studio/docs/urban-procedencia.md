# Procedencia Urban

## Vestuario Urban · versión 1.8
Se reutilizan el traje y las superficies del visor Batucada Building Connections de LIGHTMAN, con su imagen del Catálogo Full IA. Base articulada Xbot del ejemplo Three.js/Mixamo; Three.js r180 y addons bajo MIT. Rostro de referencia: «Infinite, 3D Head Scan», Lee Perry-Smith / Infinite-Realities, conversión Morgan McGuire y Guedis Cardenas, CC BY 3.0 (https://creativecommons.org/licenses/by/3.0/), desde el ejemplo LeePerrySmith de Three.js r180 (https://github.com/mrdoob/three.js/tree/r180/examples/models/gltf/LeePerrySmith). El rostro es una referencia genérica. Adaptaciones: recorte, escala y colocación del busto; contornos blancos y LEDs vinculados a la secuencia verde/blanco. No se reasigna el patch físico de trajes.
