# Procedencia de recursos

El código de integración, el editor de timeline, la escena LASERMAN y la síntesis musical se prepararon para LIGHTMAN en esta entrega. No se establece una licencia general sobre recursos de terceros.

- `vendor/three.module.js`, `three.core.js` y OrbitControls proceden de Three.js r180, licencia MIT conservada en `vendor/LICENSE-three.txt`.
- `vendor/ldp-core.js` y la definición `assets/jacket-patch.json` proceden de los recursos públicos de LDP Studio 0.96.34-prod.1 previamente analizados y conservados en la adaptación local LIGHTMAN. El Jacket se identifica como `official-portion-x`. Sus derechos pertenecen a sus titulares. Esta entrega local no concede derechos para redistribuir esos recursos públicamente.
- `laser.js` y `fb3-wire.js` derivan del trabajo local de LIGHTMAN Laser Studio. La edición web no contiene el transporte USB, el cálculo de autenticación FB3 ni ejecutables de QuickShow, licencias personales o volcados de memoria. El control físico se conserva en el programa local.
- La chaqueta y las figuras humanas de `scene.js` y `jacket.js` son una reconstrucción mediante geometría propia. No se incluye ni se afirma haber recuperado un modelo 3D privado de LDP.
- NEON PROTOCOL es una composición instrumental sintetizada para este proyecto. Su archivo de metadatos está junto al WAV.
